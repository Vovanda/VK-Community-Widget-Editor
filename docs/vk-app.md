## Каталог

Модерация приложений сообществ приостановлена: в каталог приложений для сообществ
сейчас попадают только приложения на платформе VK Mini Apps. Сменить тип можно в
настройках, но **смена необратима**. До неё нужен переезд с `xd_connection` на
VK Bridge, иначе предпросмотр и права перестанут работать во всех группах.

Порядок: [#1 VK Bridge](https://github.com/Vovanda/VK-Community-Widget-Editor/issues/1),
потом [#2 тип Mini App и заявка в каталог](https://github.com/Vovanda/VK-Community-Widget-Editor/issues/2).

## Предложение для «Краткого описания» и «Описания»

Главное — универсальность и конструктор: один редактор на все основные типы
виджетов, наполнять их можно без кода. Код — второе, для тонкой настройки.
«Все основные», а не «все»: тип Text в редакторе убран намеренно.

Краткое описание:

> Универсальный редактор виджетов сообщества с визуальным конструктором

Описание:

> Универсальный редактор виджетов для сообществ ВКонтакте. Поддерживает все основные
> типы виджетов: List, Table, Tiles, Compact list, Cover list, Match, Matches и
> Donation. Визуальный конструктор помогает наполнить виджет без кода: строки, плитки,
> кнопки и ссылки добавляются в форме, а код редактор собирает сам. Для тонкой
> настройки есть редактор VKScript, и форма понимает написанный вручную код.
> Предпросмотр показывает виджет средствами VK до установки. Сделано в SawKing Tech:
> sawking.tech. Исходный код открыт: github.com/Vovanda/VK-Community-Widget-Editor
