# Редактор виджета ВК сообщества

Универсальный редактор виджетов сообществ VK: все типы виджетов в одном
месте, а визуальный конструктор помогает их наполнить без кода. Для тонкой настройки
есть редактор VKScript; предпросмотр показывает виджет прямо во ВКонтакте.

- Открыть приложение: [vk.ru/app7100465](https://vk.ru/app7100465).
- Настройки приложения, для владельца: [vk.ru/editapp?id=7100465](https://vk.ru/editapp?id=7100465).
- Состояние приложения в VK, картинки для настроек и путь в каталог: [docs/vk-app.md](docs/vk-app.md).

Сама страница лежит на [GitHub Pages](https://vovanda.github.io/VK-Community-Widget-Editor/),
но вне VK предпросмотр и права не работают: они вызываются через VK.

## Случайный виджет

В VKScript нет `Math.random`, а внешние запросы из кода виджета закрыты. Случайность
здесь берётся из социального графа: `API.friends.get` с `order: "random"` у
донорского профиля отдаёт случайных друзей, и из их id получаются числа от 0 до 1.
Скорее всего, такого виджета в VK больше нет ни у кого.

Разбор подхода — в [gist «Случайность в VKScript»](https://gist.github.com/Vovanda/b47f75287542eb1f62704d5881b3d1d8).

Вживую:

- [Питомник ВЕО «Омская Дружина»](https://vk.ru/veoomsk) —
  `templates/veoomsk/RandomTextInWidget.vks`: приветствие по времени суток посетителя
  и сообщение из случайной темы; какие темы доступны, зависит от того, состоит ли
  человек в группе.
- [vk.ru/veopuppy](https://vk.ru/veopuppy) — `templates/veopuppy/RandomTextInWidget.vks`:
  то же для группы объявлений о щенках; случайность там считается от времени
  последнего визита посетителя.

## Что на экране

| | |
|---|---|
| **Форма и Код** | два вида одного кода. Форма находит в скрипте виджет и списки нужной формы, в том числе вынесенные в переменные, и правит их полями; всё остальное — во вкладке «Код» |
| **Отменить, повторить** | история редактора, `Ctrl+Z`, `Ctrl+Y`; переживает перезагрузку страницы, до 200 шагов |
| **Тип виджета** | все девять типов VK, List первым, Text последним; у каждого свой код и своя история отмены |
| **Сниппеты** | вставляют в начало кода рандомайзер или приветствие по времени суток — редкие для виджетов возможности; чтобы встроить их в свой виджет, нужны навыки программирования или помощь ИИ-ассистента |
| **Версии** | код, каким он был час назад или в прошлые дни: за сутки по часам, дальше по дню, неделю назад; выбор версии отменяется как любая правка |
| **Шаблон** | пример кода для выбранного типа; доступен только при пустом коде, чтобы не затереть готовый |
| **Форматировать** | js-beautify; синтаксис VKScript `@.` не рвёт, однострочные объекты оставляет в строку |
| **Права на виджет** | просит администратора разрешить приложению обновлять виджет сообщества |
| **Предпросмотр** | показывает виджет средствами VK; `Ctrl+Enter` |
| **Сообщения** | ошибки предпросмотра от VK; повторы схлопываются в одну строку, видны последние десять |

Кнопки — иконки, текст выезжает внутри кнопки при наведении: VK показывает
приложение в колонке шириной около 650 px, и подписи в полную ширину рвали панель
на несколько рядов. На телефоне наведения нет, поэтому там подписи видны сразу,
а кнопки стоят по две в ряд.

## Как это устроено

- **Статика без сборки**: `index.htm`, `style.css`, `widget-types.js` (типы виджетов,
  их схемы и шаблоны), `widget-form.js` (форма), `widget-editor.js` (редактор и связь
  с VK). Pages отдаёт сайт из ветки `main`, так что пуш в `main` — это и есть выкладка.
- **Библиотеки лежат в `vendor/`**: CodeMirror 5.65.16, js-beautify 2.0.3,
  Font Awesome 6.5.0, acorn 8.18.0 (разбор скрипта для формы). С cdnjs их не берём:
  он работает на Cloudflare, а Cloudflare в России режут, и редактор без CodeMirror
  у пользователей просто не открылся бы.
- **Цвета из токенов VKUI**, тёмная тема включается по настройке системы.
- **Код хранится в localStorage браузера**: код, история отмены и версии, у каждого
  типа свои. Если VK передаёт id сообщества в адресе фрейма (`group_id`), у каждого
  сообщества своё хранилище; передаёт ли он его на самом деле, в VK ещё не проверено.
  Историю прежней версии редактора (`vk_widget_editor_state`) новая не удаляет:
  из неё берётся последняя версия кода, а сама история остаётся на месте.

## Проверка

```bash
python -m http.server 8743 &
npm i --no-save playwright && npx playwright install chromium    # разово
node tools/smoke.mjs
```

Смок открывает страницу настоящим браузером с заблокированным cdnjs: проверяет, что
скрипт не упал, типы переключаются, отмена, шаблон, сниппеты, версии и форматирование
работают, форма находит блоки в реальном скрипте и правит их, код и история отмены
переживают перезагрузку, старая история цела, в VK уходят правильные вызовы (на
поддельном объекте VK), журнал не копит мусор, панель стоит в один ряд на ширине
фрейма VK, вёрстка не уезжает вбок от 320 до 1920 px, обе темы красят фон, а на
телефоне подписи кнопок видны. Вёрстку всё равно смотрят глазами.

## Известные ограничения

- Работает только внутри VK: вне фрейма приложения кнопки предпросмотра и прав
  выключены, и страница об этом пишет.
- Код живёт в одном браузере: в другом браузере, на другом компьютере или после
  очистки данных сайта редактор откроется пустым. Редактор предупреждает об этом
  под кодом; резерва файлом пока нет.
- Связь с VK идёт через старый `xd_connection`; документация VK сейчас описывает
  установку виджетов через VK Bridge.
